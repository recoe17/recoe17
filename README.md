## Featured work — HIPH (Collaborator)

### Chenjerai — Student & Finance Platform
**Collaborator** · Private repo · Next.js · TypeScript · Prisma · Drizzle · Clerk · Vercel

Production platform used daily by **registry**, **finance**, and **cashiers** at HIPH.

**64+ commits** · **~9,700 lines added**

| Area | What I built |
|------|----------------|
| **Exam fees** | Semester-scoped exam billing, auto-calculation, revision rewrites, ND/NC rate mapping, split bank + cash capture, God-mode edit dialog, cashier filters for bursar review |
| **Fee reallocation** | Full bursar workflow to split payments across tuition / revision / exam, hold leftover as **Unallocated credit**, email bursar + registrar, dedicated student profile tab |
| **Revision billing** | Per-module rate history, semester grouping, bursar choice to keep or reprice modules, bridging for students without a current level |
| **Finance reports** | Zimbabwe timezone boundaries (CAT), late-night payment attribution, POP date handling, report-day column on dashboards |
| **Fee waivers** | Superadmin initiation workflow with Prisma migration and registrar/bursar notifications |
| **Uniform module** | Cashier uniform sales with receipt printing workflow |
| **Access control** | Effective-period cutoff tiers for 80%+ paid students |
| **NFC programmes** | Excluded short-course programmes from semester rollover rules |
